# Screenshots and Demo Assets

This directory contains visual assets for the README.

## Required Assets

Please add the following files to make the README more visually appealing:

### 1. Banner Image
- **Filename**: `banner.png` or `banner.jpg`
- **Recommended size**: 1200x400 pixels
- **Content**: Project logo with tagline
- **Tools**: Canva, Figma, or Photoshop

### 2. App Screenshots
Add 2-3 high-quality screenshots of the main app features:

- `screenshot-onboarding.png` - Onboarding/splash screen
- `screenshot-profile.png` - Profile creation view
- `screenshot-matching.png` - Matching/swiping interface
- `screenshot-reveal.png` - Match reveal screen (optional)

**Recommended**: Take screenshots directly from iOS Simulator or device
- iOS Simulator: Cmd+S to save screenshot
- Size: Use actual device resolution

### 3. Demo GIF
- **Filename**: `demo.gif`
- **Duration**: 10-15 seconds
- **Content**: Quick walkthrough of key features
- **Tools**: 
  - [LICEcap](https://www.cockos.com/licecap/) (Windows/Mac)
  - [ScreenToGif](https://www.screentogif.com/) (Windows)
  - [Kap](https://getkap.co/) (Mac)
  - QuickTime + online converter

## How to Add

1. Record your app demo
2. Take screenshots of key screens
3. Create a banner using design tools
4. Add files to this directory
5. Update image paths in README.md

## Tips

- Use consistent styling across all images
- Ensure screenshots show the app's best features
- Keep GIF file size under 10MB for faster loading
- Consider using image optimization tools to reduce file sizes
